## Findings considered and rejected

- Replacing the existing `@ai11y/core` `plan()` implementation with JEV was
  rejected because JEV is a structured decision model rather than a text/chat
  model, and replacement would break normal LLM and rule-based behavior.
- Adding `"jev"` to the existing `AgentMode` union was rejected for the first
  release. A dedicated subpath keeps JEV's non-conversational response and loop
  semantics out of the stable `{ reply, instructions }` API.
- Asking JEV to generate arbitrary routes or form text was rejected. JEV is not
  a generative model; the integration must give it bounded candidates and keep
  exact parsing and execution in code.
